# CFB 27 Team Needs

Standalone CFB 27 roster-planning utility. Import a dynasty save, select a school, and automatically populate current roster counts and graduating players. Transferring, Being Cut, and Recruited remain manual planning fields and are remembered per team.

The app intentionally reads only the Team and Player tables needed for Team Needs. It does not depend on the Dynasty Tracker's recruiting, schedule, history, or Coach-table parsing.

Development is local-first. GitHub Actions are manual-only and never run automatically on pushes or pull requests.
